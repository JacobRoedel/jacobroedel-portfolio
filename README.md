# Jacob Roedel

Personal portfolio for Jacob Roedel, a Software Engineer II at Dell Technologies working on agentic applications and telemetry systems.

## Projects

- [Beacon](https://beacon.jacobroedel.dev) — a read-only personal-finance agent that monitors financial data and surfaces grounded recommendations.
- [Loadout](https://github.com/JacobRoedel/loadout) — a local, read-only development-environment readiness checker written in Rust.

## Local preview

This is a dependency-free static site. Open `index.html` in a browser, or serve this directory with any static-file server.

## Deployment

The site is deployed from the `main` branch through Vercel. Custom-domain configuration is managed in the Vercel project settings.
